打造自己的對話機器人

用 system prompt 給 AI 人設，再用 AISuite 寫出自己的聊天機器人。

  • System Prompt
  • AISuite
  • 負責任使用

01本週一句話

一個對話機器人，就是用 system prompt 設定人設，再把整段對話歷史一起送給 LLM。

02重點整理

對話裡有三種角色

system 是人設與規則，user 是使用者說的話，assistant 是 AI 的回覆。每次呼叫 API 都要把整串對話歷史送過去，模型才「記得」前面說過什麼。

人設的威力

課堂示範「員瑛式思考」（Lucky Vicky）：不管遇到什麼事，都用正向的第一人稱口吻說明為什麼很幸運。只要加一段 system prompt，同一個模型就像換了一個人。

和 AI 一起寫 system prompt

先和 AI 討論，請它收集資料；自己核對並修正錯誤（例如書名的正確譯名）；再請 AI 用 Markdown 整理成 system prompt；最後一定要自己讀過、修改。

小心太會說的機器人

小編助理、股票分析師、選系諮商師都做得出來。只會推薦某個科系的諮商師也說得頭頭是道，所以不要因為 AI 講得有道理就照單全收。

用 AISuite 寫程式

吳恩達老師的 AISuite 用統一的寫法呼叫不同廠商的模型，換模型只要改一個字串。API 金鑰放在 Colab 的 Secrets，不要直接寫在程式裡。

負責任地使用 AI

AI 生成的都是幻覺，一定要讀過再用。不要貼個資、機密或考題，雲端對話紀錄可能外洩。輸出有沒有侵權、正不正確，是使用者的責任。

03核心程式

system：人設+user：問題+assistant：回覆+user：再問→LLM
import aisuite as ai
      client = ai.Client()

      messages = [
          {"role": "system", "content": "你的人設與規則"},
          {"role": "user", "content": "使用者的輸入"},
      ]

      response = client.chat.completions.create(
          model="openai:gpt-4o",   # 換模型只要改這裡
          messages=messages)

      reply = response.choices[0].message.content

想用開源模型的話：

方式特色
LM Studio有圖形介面，用起來像一般聊天 App
Ollama簡潔的終端機工具；Ollama Cloud 可以在雲端跑超大模型（需訂閱）
Groq免費 API、速度很快，但可選的模型不多

真正在自己電腦上跑模型、資料不外傳，就能避開把對話交給雲端服務的風險。至於使用中國模型，比起「刻意審查」，更要留意的是訓練資料裡的價值觀，可能潛移默化影響經常使用的人。

04名詞小辭典

System Prompt
對話開始前給 AI 的人設與規則。
User / Assistant
對話中使用者和 AI 這兩種角色。
API 金鑰（API Key）
呼叫模型服務的密碼，不能公開。
AISuite
吳恩達老師的 Python 套件，用同一套寫法呼叫各家模型。
LM Studio / Ollama
在自己電腦上跑開源 LLM 的工具。
VRAM
顯示卡記憶體，決定能跑多大的模型。
心智理論（Theory of Mind）
理解他人想法的能力；有人發現 GPT 的表現接近，但不代表它有意識。

05自我測驗

Q1. 為什麼每次呼叫 API 都要送整串 messages？

LLM 本身不會記得上一次對話，必須把對話歷史一起送過去，它才知道前面聊了什麼。

Q2. system、user、assistant 各代表什麼？

system 是人設與規則；user 是使用者的輸入；assistant 是 AI 的回覆。

Q3. 請舉出兩個負責任使用 AI 的做法。

例如：AI 生成的內容一定要自己讀過再用；不要把個資、機密或考題貼給雲端 AI；自己確認有沒有侵權、資訊對不對。
