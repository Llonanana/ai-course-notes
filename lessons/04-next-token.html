LLM 只是在猜下一個字？

LLM 是看過超多文字的接話高手，溫度與 top-p 決定它怎麼選字。

  • LLM
  • Temperature
  • Embedding

01本週一句話

LLM 只做一件事：看前面一堆字，猜下一個字，只是它讀過的字比人一輩子讀的多上萬倍。

02重點整理

不是用對話來訓練

對話機器人並不是拿「客服問答」訓練出來的，而是用前面的字預測下一個字。這樣一來，世界上所有句子都能拿來當訓練資料。

一個字一個字接下去

每個字都有編號。模型對所有可能的字算出分數，經 softmax 變成機率，抽出一個字接上去，再把它當成新的輸入，一路生成下去。

幻覺是特色，不是 bug

Karpathy 說 LLM 是「作夢的機器」，它生成的內容本來就是幻覺，可能對、可能錯，甚至無所謂對錯。訓練目標是讓它很會接話。

讀過非常多東西

人一輩子大約讀 10 億字的量級；Llama 的訓練資料約 15T，是人類的 1.5 萬倍。所以幾乎什麼話題它都接得上。

Embedding：字的意思

One-hot 只是編號，沒有意思。Word2Vec 用「周圍的字猜中間」或「中間猜周圍」這類代理任務，學出帶有意思的向量，相似的字會靠在一起。

Prompt 只有兩個重點

正確的資訊加上清楚的指引。最好的做法是和 AI 一起寫 prompt：補充只有你知道的內容、請 AI 反問你、整理成草稿，最後自己讀過並修改。

03核心公式

Pθ( 下一個字 = wᵢ ∣ x₁, x₂, …, xT )
prompt→算出每個字的機率→依策略抽一個字→接到句子後面→重複

三種選字策略：

策略怎麼做效果
Temperature τsoftmax 前把分數除以 ττ > 1 更隨機；τ < 1 更固定。實務上常設 τ = 1
Top-k只從機率前 k 名抽，例如 k = 50避免抽到很冷門的字；但有時候只有一個字合理
Top-p從最高的字開始累加，直到超過 p（例如 0.9）候選字數量自動調整，也叫 nucleus sampling
✗ 陽春 prompt請介紹某個偶像團體。（得到一篇中規中矩、沒有感情的文章）
✓ 好的 prompt請用粉絲的角度介紹這個團體，要包含出道時的高峰、低潮的那一年、最新專輯想傳達的態度……（補上只有你知道的內容）

想在自己的電腦跑開源模型？以 4-bit 量化估算，200 億參數的模型大約需要 0.5 × 20 = 10 GB 的 VRAM，實際建議 16 GB。

04名詞小辭典

大型語言模型（LLM）
用大量文字訓練、會預測下一個字的模型。
幻覺（Hallucination）
LLM 生成的內容；可能是對的，也可能是錯的。
溫度（Temperature）
調整選字隨機程度的參數。
Top-k
只從機率前 k 名的字裡抽。
Top-p（Nucleus Sampling）
從機率最高的字開始累加到 p，只在這些字裡抽。
詞嵌入（Word Embedding）
代表一個字意思的向量。
代理任務（Pretext Task）
為了學出好的表示向量而設計的小任務，不是最終目的。

05自我測驗

Q1. LLM 為什麼能用「世界上所有句子」來訓練？

因為它的任務是用前面的字預測下一個字，任何一句話都能拆成很多組「前文 → 下一個字」的訓練資料。

Q2. 把 temperature 調高會發生什麼事？

各個字的機率會被拉近，選字更隨機、更有變化；調低則會更固定。

Q3. 寫好 prompt 的兩個重點是什麼？

正確的資訊（把背景和條件講清楚）加上清楚的指引（要做什麼、輸出成什麼樣子、給誰看）。

06我的心得

「LLM 是唬爛王」這個說法讓我印象很深。它不是在查資料，而是在接話，所以它說的話我一定要自己讀過、自己判斷。

和 AI 一起寫 prompt 的技巧很實用。以後我不會只丟一句話，而是先請 AI 反問我，把需求釐清再開始寫。
