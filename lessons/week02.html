神經網路的概念

神經網路是一台函數學習機，靠 loss 與梯度下降慢慢學會。

  • 神經元
  • Softmax
  • 梯度下降

01本週一句話

神經網路是一台函數學習機：先隨便猜，再用 loss 算出錯了多少，用梯度下降一點一點修正。

02重點整理

輸入輸出都要是數字

AI 只吃數字。更精確地說，輸入和輸出都是張量（tensor）：純量是 0 階、向量是 1 階、矩陣是 2 階。例如用過去 20 天、每天 N 個特徵預測股價，輸入就是 20 × N 的數字。

分類：one-hot 與 softmax

三種八哥用 one-hot 編碼成 [1,0,0]、[0,1,0]、[0,0,1]。模型輸出三個分數，經過 softmax 變成加起來等於 1 的比例，例如 61%、28%、11%。

神經元怎麼算

把輸入乘上權重後加總，再加上偏值（bias），最後通過激發函數（例如 ReLU）送出。權重和偏值都是學來的，合起來叫參數 θ。

打造 DNN 只要決定兩件事

要幾層隱藏層、每層幾個神經元，每層之間完全連結。其他兩大天王：CNN 擅長圖形辨識，RNN 有記憶。不管哪種，基本單元都是神經元。

訓練就是讓 loss 變小

架構固定後，θ 一決定，函數就決定了。loss function 計算模型答案和正確答案差多少，訓練的目標就是找出讓 loss 最小的 θ*。

梯度下降：往斜率反方向走

切線斜率為正，就往左移；斜率為負，就往右移。乘上學習率 η 避免一次走太多跑過頭。參數不只一個時，就每個都做偏微分，合起來就是梯度。

03核心公式

一個神經元的計算：

h = φ( w₁x₁ + w₂x₂ + w₃x₃ + b )

Softmax：先做指數轉換確保都是正數，再按比例分配：

pᵢ = e^{aᵢ} / (e^{a₁} + e^{a₂} + … + e^{aₙ})

梯度下降：所有參數一起往 loss 變小的方向調整：

「萬能近似定理」證明：只要一層夠寬的隱藏層，神經網路就能逼近你想學的函數。上個世紀神經網路沒有成功，是因為當時缺少足夠的算力、大量數據和好用的軟體。

04名詞小辭典

張量（Tensor）
一堆排好的數字；純量、向量、矩陣都是張量。
One-hot 編碼
類別有幾種就用幾維向量，正確那一格是 1，其他是 0。
Softmax
把任意分數轉成全為正、加起來等於 1 的比例。
激發函數（Activation Function）
讓神經網路不只是線性計算，最常用的是 ReLU。
損失函數（Loss Function）
衡量模型答案和正確答案差多遠，越小越好。
梯度下降（Gradient Descent）
沿著梯度的反方向調整參數，讓 loss 變小。
學習率（Learning Rate）
每次調整的步伐大小，太大會跑過頭。
反向傳播（Backpropagation）
梯度下降用在神經網路時的名稱（因為神經網路的特性）。

05自我測驗

Q1. 為什麼分類問題要做 softmax？

讓輸出全部是正數且加起來等於 1，方便解讀成「有幾成可能是這一類」，也就是所謂的機率分布。

Q2. 一個神經元裡，哪些數字是要學習的？

權重 w 和偏值 b，合起來就是參數 θ。

Q3. 梯度下降為什麼要乘上學習率？

避免一次調太多、跑過最低點。學習率讓每一步走得小一點、穩一點。
