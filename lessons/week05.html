AI 怎麼記得前面說過什麼？

從 RNN 到 Transformer：注意力機制讓每個字都能回頭看全文。

  • RNN
  • Attention
  • Transformer

01本週一句話

Transformer 讓每個字都能回頭「注意」前面所有的字，而且一次算完，不必像 RNN 一個字一個字讀。

02重點整理

RNN：把記憶傳回來

RNN 神經元和一般神經元一樣，只是除了這次的輸入，還會接收上一次的輸出 ht−1 當作記憶。缺點是必須一個字接一個字算，很慢。

Attention：Q、K、V

每個字都產生三個向量：query（問題）、key、value。拿 q 跟每個 k 做內積，得到相關強度，經 softmax 變成權重，再把所有 v 加權相加。

Self-attention 與多頭

Self-attention 就是每個字輪流當 q。整個過程只是矩陣乘法，可以一次算完。用好幾組不同的 W 各算一次，就是 multi-head attention。

為什麼要除以 √dk

Softmax 是「贏者通吃」，分數差一點，權重就差很多。把分數除以一個數、拉回 0 附近，權重就會比較平均。

位置編碼

一次平行計算的話，模型不知道字的先後順序，所以要在詞嵌入加上位置資訊。原論文用不同頻率的 sin、cos，就像好幾個轉速不同的時鐘。

讓網路又深又穩

ResNet 的跳接把輸出變成 z + ℓ(z)，每層只需要學還沒學到的部分。再搭配 Layer Normalization（Llama 用 RMSNorm），深層網路也能穩定訓練。

03核心公式

Attention(Q, K, V) = softmax( QKᵀ / √dk ) V
字→詞嵌入 + 位置編碼→Q = XWQ, K = XWK, V = XWV→多頭注意力→更懂上下文的向量

Transformer 不只能處理文字，圖像、聲音、時間序列都可以。文字生圖時，就是用注意力把文字的意思「混入」圖像。本週作業：和 AI 討論出規格書，用 Vibe Coding 做一個 index.html，並用 GitHub Pages 公開。

04名詞小辭典

RNN（遞歸神經網路）
會把上一次的輸出傳回來當記憶的神經網路。
隱藏狀態（Hidden State）
RNN 傳給下一步的「記憶」向量。
Query / Key / Value
注意力機制中，每個字的三種特徵代表向量。
自注意力（Self-attention）
句子裡每個字輪流當 query，去注意其他所有字。
多頭注意力（Multi-head）
用好幾組權重同時做注意力，看不同面向的關係。
位置編碼（Position Encoding）
加進詞嵌入的位置資訊，讓模型知道字的順序。
殘差連接（Residual / ResNet）
輸出 = 輸入 + 這層學到的東西，讓網路可以很深。
層正規化（Layer Normalization）
把一層的數值調整到平均 0、標準差 1，讓訓練更穩。

05自我測驗

Q1. Transformer 為什麼比 RNN 快？

RNN 必須一個字一個字依序算；Transformer 的注意力只是矩陣乘法，可以一次平行算完。

Q2. Q 和 K 做內積的結果代表什麼？

代表這個字（query）和另一個字（key）的相關強度，經 softmax 後就是加權 value 的權重。

Q3. 沒有位置編碼的話會出什麼問題？

Transformer 是同時處理所有字，本身不知道字的先後順序，字的先後順序資訊就消失了，所以要另外加上位置編碼。
